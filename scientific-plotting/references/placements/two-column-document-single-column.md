# Single-Column Placement in a Two-Column Document

This file applies to figures that occupy one column in a two-column document without spanning both columns. Exact dimensions or complete coordinate positions provided by the user take precedence over the corresponding defaults in this file. Apart from the pure time-series, independent coordinate-plot, and bifurcation and Lyapunov exponent comparison presets below, no default physical dimensions currently exist for other plot types; do not borrow the canvas, plot boxes, or coordinate positions from the full-width placement for a one-column document.

## 1. Pure Time-Series Plots

Applies to the [pure time-series workflow](../plot-types/pure-time-series.md). Use the standard layout below unless the user requests the compact arrangement in Section 8.

- Every internal plot box defaults to `65 mm` wide, subject to the scoped `60 mm` fallback in Section 4. If the entire figure contains exactly one panel and exactly one data waveform, its default height is `12 mm`; otherwise, multiple data waveforms or multiple panels make every box's default height `15 mm`. A user-specified width or height overrides only that corresponding field. These dimensions exclude tick labels, axis labels, legends, panel labels, and external annotations. Use `PositionConstraint = 'innerposition'` and measure between frame-line centers in the final PDF; each dimension must be within `0.1 mm` of its configured value.
- Arrange one or more panels vertically in one plot column, with aligned left and right frame borders, preserving the specified panel order from top to bottom. For an explicit request to place exactly two panels side by side, apply Section 8. Other requests for two plot columns fall outside this preset; resolve them with the user without borrowing a wider placement's layout.
- Use the `each-panel`, `shared-bottom`, or `hidden` horizontal-axis text mode defined in the plot-type file. A single panel defaults to `each-panel`; multiple panels with identical time ranges and ticks default to `shared-bottom`. The vertical-axis mode defaults to `single-y`; use `split-y` only after the user explicitly requests separate axes for multiple variables and confirms the left/right axis mapping.
- Obtain the actual extents of the tick text, xlabel, left and right y-labels, panel labels, and any requested legends or external annotations in the final font. Calculate the four margins and vertical gaps from these extents plus explicitly configured padding. `each-panel` must reserve space for each panel's complete horizontal-axis text; `shared-bottom` reserves it only on the last occupied panel; use `hidden` only when an external shared horizontal axis already exists or the user explicitly requests it.
- Calculate the complete canvas from the panel count, horizontal-axis text mode, vertical-axis mode, and measured text, and set an explicit page width and height for the final PDF. Do not rely on automatic tight cropping to determine page dimensions or hard-code gaps inferred from screenshots. Record the resulting geometry in the task script.
- Retain the configured frame heights and the common `Times New Roman`, `8 pt` main-text default when more surrounding space is needed. Select frame widths and check the complete native canvas under Section 4. Its default-width fallback is the only automatic frame-width change allowed for a width conflict; do not stretch frames, reduce the font, clip text, or scale the figure to fit.
- After Section 4 selects the frame widths, `split-y` adds the necessary space for right-axis text without changing the selected internal frame dimensions further. Handle the variables, units, ranges, and ticks on the left and right axes according to the plot-type file and the user-confirmed configuration.
- All physical dimensions and font sizes refer to the exported file at its native size. Additional panels change the surrounding layout, not the configured frame dimensions.

## 2. Independent Two-Dimensional Coordinate Plots

Applies to the [independent two-dimensional coordinate-plot workflow](../plot-types/independent-2d.md), without imposing a particular scientific plot family. Use the standard layout below unless the user requests the compact arrangement in Section 8.

- Default to one independent plot with a `65 mm × 45 mm` internal plot box, subject to the scoped `60 mm` width fallback in Section 4. These dimensions exclude tick text, axis labels, legends, panel labels, and other surrounding text. Dimensions explicitly specified by the user override the corresponding fields. Use `PositionConstraint = 'innerposition'` and verify the actual box in the final PDF by measuring between the frame-line centers; each dimension must be within `0.1 mm` of its configured value. Aspect-ratio constraints must not silently reduce the actual drawing box.
- Keep the plot's complete coordinate labels and independently configured ranges. For an explicit request to place exactly two plots side by side, apply Section 8. Other arrangements with multiple plots require an explicit task configuration.
- Measure all visible text in its final font, including negative tick values, subscripts, and any requested outside legends or annotations. Derive the four margins and complete canvas from those measured extents plus explicitly configured padding. Record the resulting dimensions in the task script and set the final PDF page size explicitly. Retain the common `Times New Roman`, `8 pt` main-text default; the complete figure width is not fixed at approximately `70 mm`, and no canvas dimensions are borrowed from another placement.
- Preserve the internal box height and font size when more surrounding space is needed. Select the frame width and check the complete native canvas under Section 4. A compact frame alone does not guarantee that every set of surrounding labels fits. Except for that default-width fallback, do not shrink the box, reduce the font, clip text, or scale the exported figure to fit.
- All physical dimensions and font sizes refer to the exported file at its native size. Enlarging surrounding whitespace does not enlarge the internal plot box.

## 3. One-Dimensional Bifurcation and Lyapunov Exponent Comparisons

Applies to the [one-dimensional bifurcation and Lyapunov exponent comparison workflow](../plot-types/bifurcation-lyapunov.md). Each comparison group contains a bifurcation plot above a Lyapunov exponent plot. Use the standard layout below unless the user requests the compact arrangement in Section 8.

- Default to one comparison group. The upper internal plot box defaults to `65 mm × 30 mm`; the lower internal plot box defaults to `65 mm × 15 mm`, subject to the scoped `60 mm` width fallback in Section 4. These dimensions exclude tick text, axis labels, legends, panel labels, and other surrounding text. Dimensions explicitly specified by the user override the corresponding fields. Align the upper and lower frames on their left and right borders; resolve any conflict between explicit dimensions and the requested alignment. Use `PositionConstraint = 'innerposition'` and measure each actual box between the frame-line centers in the final PDF, within `0.1 mm` of each configured dimension. Aspect-ratio constraints must not silently reduce the actual drawing boxes.
- For an explicit request to place exactly two comparison groups side by side, apply Section 8. Other arrangements with multiple groups require an explicit task configuration.
- Apply the plot-type file's conditions for sharing the horizontal axis within the group. When those conditions hold, reserve horizontal-axis text only below the lower box. Otherwise reserve complete horizontal-axis text below both boxes. Keep the two vertical axes independently labeled and configured.
- Measure all visible text in its final font, including negative tick values, subscripts, and any requested outside legends or annotations. Derive the vertical gap within the group, the four margins, and the complete canvas from those extents plus explicitly configured safety padding. Record the resulting dimensions in the task script and set the final PDF page size explicitly. Retain the common `Times New Roman`, `8 pt` main-text default; no fixed canvas or gap is inferred from a screenshot or borrowed from another placement.
- Preserve the internal box heights and font size when more surrounding space is needed. Select frame widths together and check the complete native canvas under Section 4. A compact frame alone does not guarantee that every set of surrounding labels fits. Except for that default-width fallback, do not shrink the boxes, reduce the font, clip text, or scale the exported figure to fit.
- All physical dimensions and font sizes refer to the exported file at its native size. Enlarging surrounding whitespace does not enlarge the internal plot boxes.

## 4. Default Width Fallback and Acceptance

This rule applies only to the standard layouts for pure time-series plots, independent coordinate plots, and bifurcation and Lyapunov exponent comparisons in this nonspanning placement. For the compact arrangement, use the width candidates in Section 8 instead of the `65 mm` and `60 mm` widths below.

- Use a complete-canvas width threshold of `89 mm` by default. This is a skill preset, not a universal journal dimension. Only an explicit user-specified threshold or column width overrides it; do not replace it with a value inferred from a template or screenshot. Record the threshold and its source in the task configuration.
- Keep every explicit user width locked, including `60 mm`, `65 mm`, or another value. A height-only override changes only the height and retains this default-width policy. Do not apply automatic fallback to explicit widths or override other fixed dimensions; report any conflict with required frame alignment or an explicit canvas instead.
- Begin with `65 mm` for every frame whose width is unspecified. Measure all actual text and required safety padding, calculate the full canvas, and export a preliminary PDF. Check its full page width, including any export rounding, against the threshold. If that width does not exceed the threshold, retain `65 mm`.
- If the `65 mm` result exceeds the threshold, change all frames that still use default widths in the figure to `60 mm` together. For a comparison, change its upper and lower default widths together; for a time-series stack, change every default-width panel together. Keep all frame heights, explicit dimensions, text size, data, and ordering unchanged. Remeasure the text, recalculate margins and gaps, and export again; this is a fresh layout at the fallback width, not a scale transformation of the original figure.
- If the fallback result still exceeds the threshold, or a figure with locked widths cannot fit, report the required and allowed page widths and resolve the conflict with the user. Do not reduce widths further, shrink text, clip content, scale the exported figure, or automatically change placement.
- The accepted final PDF page width must be no greater than the threshold. Measure internal frames separately between frame-line centers, within `0.1 mm` of the selected `65 mm`, fallback `60 mm`, or explicit user width and each configured height. The frame-dimension tolerance is not an allowance to exceed the page-width threshold. Inspect the final PDF-derived high-resolution preview after the accepted export, and report the selected frame width, whether fallback occurred, the threshold, and the final measured page width.

## 5. Other Plot Types

For plot types other than pure time series, independent coordinate plots, and bifurcation and Lyapunov exponent comparisons, the following information sufficient to determine the layout must be obtained from the user's current instructions or a confirmed configuration before plotting:

- Canvas width and height;
- Internal width and height of each type of plot box;
- Arrangement of multiple plots and the necessary margins and gaps, or the complete position of each plot box.

## 6. MAT Sheared Slices

For MAT sheared slices, also obtain and explicitly configure the number of columns per row, width and height of each slice, downward drop, gap between slices, row gap where applicable, all four margins, complete canvas dimensions, and colorbar dimensions or an equivalent complete position. Explicitly set inapplicable gaps to `0`. Do not call the renderer if these fields are incomplete, because its omitted values correspond to the one-column document placement. Label, tick-text, title, and tick-mark offsets may start from the plot-type defaults but must be rechecked at the actual dimensions of this placement; explicitly override the corresponding offset fields if crowding or unbalanced proportions occur.

## 7. Dimension Overrides and Missing Information

Ask only about fields that remain undetermined and affect the layout. When the user provides exact dimensions or complete coordinate positions, follow the user's current requirements; once the dimensions are obtained, apply both the main workflow and the selected plot-type file's rules. Unless otherwise specified, pure time-series plots, independent coordinate plots, and bifurcation and Lyapunov exponent comparisons use their respective standard presets in this file, with the remaining dimensions calculated from the actual text. Use the compact arrangement only on request. When dimensions for other plot types are incomplete, do not borrow another placement's presets to proceed with plotting.

## 8. Compact Side-by-Side Arrangement

- Use this preset only when the user explicitly requests exactly two units side by side within one column of a two-column article. A unit is one pure time-series panel, one independent 2D coordinate plot, or one bifurcation and Lyapunov exponent comparison group. Both units must use the same plot type. Place them in one row, left to right in the confirmed order. The number of plots alone does not select this preset. Mixed plot types, other counts, and other arrangements are outside its scope.
- Default to `Times New Roman` with `7 pt` main text for this preset. Keep explicitly requested typography and dimensions fixed; do not reduce the font or height to make a candidate fit. The standard `8 pt` default and `65 mm` to `60 mm` width policy remain in effect for standard layouts.
- Use equal internal frame widths. For two time-series panels or two independent coordinate plots, default to `22 mm` height for both frames; `11 mm` is a compact height option only on explicit request. For two comparison groups, use `22 mm` for both upper frames and `11 mm` for both lower frames. Align the top and bottom frame borders in each corresponding row, and align the left and right borders within each comparison group. Explicit dimensions or positions override their respective defaults; if they conflict with the required alignment or fit, report the conflict rather than changing them.
- Keep each unit's complete x-axis labels and tick text. For comparison groups, retain the existing conditions for sharing x within each group, including lower-only x text when eligible; both groups still show their own horizontal-axis text. Do not omit either unit's horizontal-axis text for sharing across units or to fit the column.
- Default to independent y-axes with complete y-axis text on both units. Share y only when requested or confirmed by the user and the corresponding axes have the same verified variable meaning, units, transformation, scale, display multiplier, limits, and ticks. In a shared row, keep both frames and tick marks, retain the left y-axis tick labels and label, and omit only the duplicate y-axis text on the right. If sharing is incompatible or cannot be verified, explain why and keep both rulers complete. Do not change ranges, convert units, or normalize samples to create a match. A time-series pair with `split-y` can use this arrangement but cannot share y; keep every configured ruler and its text.
- For comparison groups, assess y-axis compatibility separately for the two upper frames and the two lower frames. Share only requested or confirmed rows that satisfy the compatibility requirements, leaving the other row's rulers complete. One shared row is enough to use the shared-y width sequence. Do not share y between the upper and lower frames of a group.
- With independent y-axes, try equal frame widths of `33 mm` and then `29 mm`. With confirmed shared y on at least one corresponding row, try `35 mm`, `33 mm`, and then `29 mm`. Choose the first width that fits and preserves readable text and the required alignment. An explicit common frame width is locked; check that width without trying alternatives. A height-only override does not lock the width.
- Use the `89 mm` complete-canvas threshold and explicit-user-override rule from Section 4. For each candidate, derive the full canvas and inter-unit gap from actual text extents and safety padding, including labels, ticks, legends, and external annotations. Rebuild the layout at each width without changing the data, confirmed ranges and ticks, or sharing mode. Check the actual native PDF page width including export rounding. The accepted page width must not exceed the threshold, and each internal frame measured between frame-line centers must be within `0.1 mm` of its configured dimensions. Inspect the final PDF-derived high-resolution preview for readability, alignment, clipping, and overlap.
- If no permitted width fits, report the attempted widths and measured page widths, the threshold, and the reason for the conflict. Do not try narrower widths, reduce the font or heights, hide other labels, scale the PDF, or change the arrangement or placement without a user instruction. Record the selected dimensions, candidate measurements, threshold and its source, y-axis sharing, and explicit overrides in the task configuration and results.
